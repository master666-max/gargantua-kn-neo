## 0. 摘要

gargantua-kn-neo 是一个 **Kerr–Newman（带电荷）黑洞光线追踪渲染器**，跑在浏览器 WebGL2 里，60 fps，参数域覆盖 **M 正负、a 与 Q 正负（含裸奇点）**，并且带一层**物理偏振（EVPA）与 GPU 上的平行输运**。

它有别于普通"黑洞演示"的三件事：

1. **一个双精度 CPU 孪生**：同一套物理在 JS 里用 double 重写，两个实现互相检验——不是拿自己证明自己。
2. **一个精确守恒律做裁判**：Penrose–Walker 常数，不含基底、不含 Gram 矩阵、不含角度。它给出的判定是"渲染器比项目自己的 CPU 参考更准"，这是可判定结论，不是修辞。
3. **一套记录被证伪假说的纪律**：README 100+ 节，每一节写"我错了什么"，不止写成功项。

## 3. 成果 B：偏振与 GPU 平行输运

这是这个项目里技术含量最高、也最容易做假的一层。

### B1 实现路径与最关键的坑

偏振向量 f 沿测地线的平行输运：

    df^μ/dλ = −Γ^μ_{σν} p^σ f^ν

关键不在于写对这个方程，而在于**它和测地线积分器的耦合**：早期把输运放在"每 N 步、几何冻结"的独立环节，实测模长涨到 **4.267**（应恒为 1）。修法是让 f、gA、gB 在测地线 RK4 的每一个阶段（ys[1..3]）一起前进，残差降到 ≤ 7.8e-5。

### B2 三个不变量断言

| 断言 | 含义 | 状态 |
|---|---|---|
| p·p = 0 | 零条件 | `dbg-step-null.mjs`：3.33e-16 |
| f·p = 0 | 偏振与动量正交 | `dbg-polbasis.mjs`：−2.78e-17 |
| \|f\|² = 1 | 模长守恒 | 同上：1.000000000000 |
| 视图 23（\|f\|²−1 的数值读出） | 全屏 R 通道 127 = 偏差 0 | 本轮实测 **97.3% 的像素为 127** |

### B3 Penrose–Walker：一个不含基底的裁判

对 Kerr，以下量沿光线**精确守恒**（Gelles 2021, Eq. 12）：

    κ = (A − iB)(r − i a cosθ)
    A = (p^t f^r − p^r f^t) + a sin²θ (p^r f^φ − p^φ f^r)
    B = [ (r²+a²)(p^φ f^θ − p^θ f^φ) − a(p^t f^θ − p^θ f^t) ] sinθ

它不含基底、不含 Gram 矩阵、不含角度——所以它不依赖"我把屏幕基选对了没有"，能独立回答"输运本身对不对"。

| 指标 | shader | CPU 参考 | 结论 |
|---|---|---|---|
| κ 相对漂移 | **2e-7 … 8e-6**（5–7 位有效数字） | 6e-5 … 1.2e-1（1–4 位） | shader 高 2–5 个数量级 |
| 像素 (800,360) | 5.6e-7 | 1.9e-3 | 差 **3400 倍** |

**这条结论改变了项目的立场**：此前多轮把 CPU 参考当"真值"去判渲染器，而精确守恒律说反了——残留误差在 CPU 那一侧。相关 harness `dbg-penrose-walker.mjs` 本轮复跑 exit 0（52.9 s）。

配对上还有一个被数据判掉的分支：**必须用逆变 p 配逆变 f**。把两者都降指标配对，漂移是 1e9–1e10 量级（`dbg-penrose-walker.mjs` 表格里的 down,down 列）。

### B4 ε 映射不是等距 → 一个 15 量子的错误

ε 把"场方向"线性映射到"偏振方向"，但**不是等距**：两个正交屏幕基向量的像并不正交，实测 **cos(gA,gB) 达到 −0.397 且不随步长变化**（说明是构造性质，不是截断误差）。

后果很硬：在那组非正交基上做 `atan2`，得到的**不是屏幕角**，偏差可达 **0.185 rad = 15 个读出量子**——比前四轮试图解释的残差还大一个量级。

修法：在**度规内**先 Gram–Schmidt（shader 与 CPU 两处都改），然后角度才有几何意义。改动是被**预测**验证的，不是事后拟合：

    (25,25) 像素：实测移动 +0.1848 rad，预测 +0.18492 rad

### B5 屏幕约定与绝对符号

- 物理屏幕 EVPA = 源处 ε 构造在**输运后的观测者基底**中的展开；
- `χ_local` = 同一个 f 在**局部横截平面**里的角度（不输运）；两者之差即输运带来的旋转——这正是论文分离"几何部分"的手法；
- Gelles 2021 的轴定义：**e_(θ) = −(1/r_s)∂_θ**（带负号）、EVPA = arctan(−f^α/f^β)，(x̂,ŷ,ẑ)↔(r̂,φ̂,θ̂)；
- 屏幕方向关系 `EVPA_Gelles = −χ + R(像素; a)`，其中 R 对 a 不敏感（a=0 与 a=0.86 分别 178.877 / 178.880，到 8 位方向量子仍相同）——**已核实**。

## 5. 成果 D：诚实的负结果与边界

负结果同样是成果——它们划定了这个渲染器能说什么、不能说什么。

### D1 论文的 1/r_s²：**符号成立，幅度测不出来**——原因是被测出来的，不是猜的

论文（Gelles 2021）的关系是 `EVPA(a) − EVPA(0) = −2a/r_s²`；取 ±a 的反对称组合后为
**`Δχ = 4a/r_s² = 3.44/r_s²`（a = 0.86）**。

下面按"障碍逐个被封闭"的顺序列出，每一行都是实测，不是推测。

| # | 障碍 | 如何被封闭 | 决定性数据 |
|---|---|---|---|
| 1 | **观测量定义错**：角度在非正交基里算 | 第 36–37 轮改为度规内 Gram–Schmidt | `cos(gA,gB) = −0.397`（不随步长变）；角偏差可达 **0.185 rad = 15 个读出量子**。修正后同一测量从 **24.1**（7 倍）变成 **4.31**（高 25%） |
| 2 | 观测半径被钳在 60 M，且盘半径与相机耦合 | 第 34 轮把盘与相机解耦 | 1/r_s² 是大半径渐近律；"推不出渐近观测者"曾是无法测量该系数的结构性理由 |
| 3 | ±π/2 折叠 | 第 29 轮换径向场 | 环向场在正对视角把 χ 压在 ±π/2 简并；垂向场投影沿视线、退化 |
| 4 | 像阶混叠 | 第 30–31 轮建像阶通道（视图 47）并过滤 | 过滤后**什么都没变**——该假设被证伪 |
| 5 | 半径混叠 | 第 42 轮把箱宽缩到 1/16 | **没有一个箱合格**（1.0 / 0.5 / 0.25 / 0.125 / 0.0625 M 全为 0 个）→ 证伪；数据转向"方位调制" |
| 6 | 方位调制 | 第 43 轮拟合 `χ(r_s,φ) = A + B cos2φ + C sin2φ` | 散布 0.031 → ~1e-3 rad，拟合非常成功；但 a = −0.86 时 `A(−a)` 整个几何变了（dA ≈ 0.79 rad vs 预测 0.005） |
| 7 | **场随自旋翻转（真正的拦路者）** | 第 44 轮加 **model 4：固定渐近笛卡尔 x 轴场** | 测量首次**受控**：A(+a)、A(−a) 都落在 0.95–0.97（同一源几何），箱间散布 0.0033 rad **首次低于**信号。结果 dA·r_s² 均值 **−0.664**（预测 +3.44）——符号相反 |
| 8 | 固有源角自带 a 依赖（混淆项） | 第 45 轮：不用输运，直接在固定坐标点算 ε 构造的固有角 | 固有角最坏 **0.0645 rad**，而预测信号在同半径只有 **0.018 rad** → **混淆项比信号大 3.5 倍**，且同为 a→−a 反对称，不抵消、只相加。账目对上：实测 −0.0016 ≈ 固有 −0.032 + 论文 +0.018 ≈ −0.014 |
| 9 | 需要逐像素分离"固有"与"输运" | 第 46–49 轮：χ_local 做成**视图 49**，一次全屏扫描同时给出两个角 | 反对称组合 **+4.62 vs 预测 +3.44**：**符号第一次正确**，幅度高 34% |
| 10 | 残留散布 | 第 50 轮：采样从 2 px 加密到 1 px（12.57 万 → 50.27 万样本） | A_local 的箱间抖动只从 0.102912 → 0.106724（**4%**）。若是拟合噪声应下降 √4 = 2 倍 → **这是真实结构**：A_local 在相邻 1 M 半径箱之间确有 ~0.1 rad 起伏；而预测信号只有 **0.002–0.026 rad** |

**最终结论（原文措辞）**：

> The sign relation is established. The magnitude cannot be measured with this method, for a
> reason that is measured rather than assumed. That is not a refutation and it is not a confirmation.

拆开说：

- **不是**论文错了；
- **不是**渲染器有 bug —— 同一像素 (800,360) 上 Penrose–Walker 给出 shader 5.6e-7、CPU 参考 1.9e-3；
- **不是**统计涨落 —— 样本翻四倍只让抖动动 4%；
- 而是：**信号（0.002–0.026 rad）处处低于一个 a 相关的真实结构（~0.1 rad）**，而该结构在反对称组合里也不抵消（输运旋转差的散布 0.095 rad，与抖动同量级）。加样本没用，因为这不是统计底噪。

**要怎样才能测出来**（第 49 轮给出的方向）：逐像素**同时**拟合 A_obs 与 A_local（而不是分箱分别拟合）、更细的 r_s 箱、或直接解 Penrose–Walker 以解析地分离固有/输运两部分。三者在本实现里都没做。

**首测数据（历史，作为"一个算错的角度"的留档）**：

    r_s    dchi       pred 3.44/r_s²   dchi * r_s²
    13.5   0.03985        0.01888           7.26
    19.5   0.03603        0.00905          13.70
    28.5  -0.05056        0.00424         -41.07
    36.5   0.06583        0.00258          87.70
    39.5  -0.00066        0.00220          -1.03

    r_s ≥ 15 的 dchi·r_s² 均值 = 24.1（预测 3.44）；散布 sd = 0.0371 rad，是最大半径处信号的 12 倍

这组数**不能**当作"论文未复现"的证据：它是用算错的角度测的，而对手（CPU 参考）又被精确守恒律证明精度更低。项目在第 41 轮明确写下："it was not evidence about the paper, and it was not evidence about the transport."

### D2 偏振物理 EVPA 逐像素对照：14 例中 9–10 例通过

失败项全部归因到**已被证明的原因**（CPU 参考在精确守恒律上精度更低），而不是"不知道"。三个互相独立的仪器在同一像素 (800,360) 上排除：

1. 观测量定义（第 37 轮修正后，shader 位移正是预测值：14.31 → 0.69 量子）；
2. 输运（Penrose–Walker：shader 5.6e-7 vs CPU 1.9e-3）；
3. 测地线采样（步长 0.15→0.05，残差 3.61→3.67 量子）。

三者指向同一侧：**残差在 CPU 参考那边**。

### D3 确定性截图：**不成立**（本轮实测）

README 顶部与 Final status 都写着"同一 URL 3 次哈希相同 / M>0 逐位精确"。本轮实测：

    同一 URL（?shot=1&t=12）加载 7 次，对应用自己的 __KN_SHOT_DATAURL 取哈希：
      2697375582 × 3   (PNG 1764890 字节)
      3216652836 × 4   (PNG 1764782 字节)
    → 7 次里 2 个不同结果，3:4，非逐位精确

是**双峰**而非噪声。判别实验：应用每次加载会隔一帧再拍第二张，**每次加载内两张完全相同**——还在演化的场景不可能如此。因此项目自己长期挂着的候选解释"预热不够（under-settled start）"**被证伪**：这是加载期的初始化分岔，不是没收敛。**未解决，如实记录。**

### D4 一个方法论结论

"渲染器 vs CPU 参考"这类对照，其可信度上限由**精度较低的一方**决定。本项目在需要高精度的地方改用**精确守恒律（Penrose–Walker）**当裁判，这是这套工作里最有迁移价值的一条经验。
